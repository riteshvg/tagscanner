TagScanner Overview
TagScanner is a utility for Adobe Tags (Launch). Get information about your active property and explore your library.
Queries you can answer
  • How do I ascertain the size of my library impacting my website?
  • Where can I get a list of elements that are significantly larger in size?
  • How many data elements are active and not used even once in any of my rules, extensions or data elements?
  • How are different data elements mapped to multiple rules?
  • How can I determine the relationships between different elements of my library?
  • and more...
Features in this release
  • CSV export of environment components and custom code
  • A component view of Data Elements, Rules and Extensions
  • Filtering Data Elements and Rules based on logic
  • Searching for variables and Events
  • Size snapshot at overall element and individual component level
  • Exporting the output as CSV
